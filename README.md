# tamil-learning-app
Created a Tamil Learning App for those who want to speak, but not read and write!

- **Plan, decisions and progress:** [docs/PLAN.md](docs/PLAN.md) (start here)
- **Setting up Supabase:** [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md)
- **What the tests check:** [docs/TESTS.md](docs/TESTS.md)

```
npm install        # once
npm run dev        # the app, at http://localhost:3000
npm test           # the tests
npm run ingest     # rebuild data/lessons.json from lessons/
```
